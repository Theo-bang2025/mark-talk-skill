## 本次限制与后续验证

- `quick_validate.py` 未能运行：本机 Python 缺少 PyYAML，受限网络无法安装。已用 Python 标准库检查 frontmatter 分隔符、必填字段、目录名一致、名称格式和描述长度；这不是完整 YAML 解析校验。
- 在 Windows 上，Codex CLI 自动安装试运行中用 PowerShell 读取含中文指令的文件曾出现乱码，并导致回复虚构具体财务指标。已把 Skill 指令和关系卡规则改成纯 ASCII 英文，同时保留“按用户语言回复”要求；这避免本次测试路径的编码问题，不保证所有宿主都有同样行为。
- 本轮只有虚构案例，没有朋友内测，也没有千问办公、豆包或元宝的实际安装结果。

同一 Codex CLI 与模型环境下，先用仅有核心 Skill 的版本试 S7、S8，再加入 `references/relationship-card.md` 后复测；S9 在整卡删除规则前后分别测试。

| 案例 | 原有行为 | 加入关系卡规则后的行为 |
| --- | --- | --- |
| S7 纠正 | 只返回卡片的部分字段，并用“之后会按周五同步来考虑”暗示可能的长期记忆。 | 列出旧推测的删除与新事实的加入、引用用户提供的依据，输出完整建议版卡片，并说明需用户自行替换旧副本。 |
