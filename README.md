# Mark Talk｜职场向上沟通助手

Mark Talk 是一个开源 Agent Skill。你可以只说一句“主管让我今晚交报告，但我做不到，怎么回？”，它会根据双方角色、当次目标和已知事实，必要时问一两个关键问题，再给出两到三条有不同取舍的回复。

首版聚焦上司、导师、带教和其他有指导、评价或决策职责的人。它帮助你思考和拟稿，消息由你选择、核对并发送。它不会自动读取微信或 QQ，也不会自动发送消息。

## 三步开始

1. 安装下面的 `mark-talk` 文件夹。整个文件夹都要保留，里面的 `references/` 是关系卡功能所需的规则。
2. 告诉 AI 当前情况、你与对方的关系和这次想达到的目标。可以只说一句话；不必上传完整聊天记录。
3. 从回复中选一条，按真实情况修改后再发送。想快一点，可以说“直接给我两条能发的回复”。

例子：

> 导师说我的初稿“论证不够扎实”。我想礼貌地问清楚该先改哪里，帮我拟回复。

Skill 会给出少量不同策略，例如直接请教重点，或列出几个**供导师确认**的可能方向。它不会断言导师真正想的是哪一种。

可能的输出形式：

> **方案一｜直接请教重点**  老师您好，收到您关于初稿论证的意见。您看我应该先集中修改哪一部分？我会按您指出的重点调整。
>
> 适用：希望先得到明确优先级。
>
> **方案二｜提出方向供确认**  老师您好，收到您的意见。我理解可能需要先补强论证依据或梳理段落逻辑，您觉得我应优先从哪一处改起？
>
> 适用：愿意主动提出可能方向；这些方向仍需导师确认。

## 安装

### Codex

下载或克隆本仓库后，将整个 `mark-talk` 文件夹放进用户技能目录：

```text
~/.codex/skills/mark-talk/SKILL.md
~/.codex/skills/mark-talk/references/relationship-card.md
```

重新开启 Codex 会话后，可以说“使用 `$mark-talk` 帮我回复导师”。[OpenAI 的 Skill 文档](https://developers.openai.com/blog/eval-skills)给出了同类用户目录和项目目录的放置方式。本项目已在 Codex CLI 中完成显式读取和项目目录安装后的中文自动触发试运行。用户目录安装与 Codex 图形界面尚未实测。

### 千问办公（QwenWork）

将整个 `mark-talk` 文件夹放进 `~/.qwenworkcn/skills/`；或在千问办公的“扩展 → 技能”入口，按界面提示安装 `SKILL.md` 和辅助文件。[千问办公官方说明](https://help.aliyun.com/zh/qwenwork/skills)列出了本地文件、技能市场和 GitHub 来源等安装方式。**本项目的仓库子目录安装与手机端使用尚未实测**；遇到导入问题时，先检查 `SKILL.md` 与 `references/` 是否一同保留。

## 关系卡

你可以让 Skill “为周导师建一张关系卡”，或把自己保存的卡片贴进下一次对话。卡片区分已确认的互动事实和附依据的待验证判断。你也可以要求“改正这一条”“删掉这个猜测”或“不要再用整张卡”。Skill 会展示修改结果与依据。

**首版不会替你保存卡片。** 若想跨会话使用，请自行保存更新后的文本，并在下次提供。删除本次输出中的内容，不会自动清除 AI 平台的旧对话、记忆或你保存的旧副本；这些需要在各自位置处理。完整规则见 [关系卡说明](mark-talk/references/relationship-card.md)。

## 提供材料时

只给当前问题有关的消息或摘要即可。请先去掉无关姓名、联系方式、公司秘密、客户资料和未公开的研究内容；确认你有权把所选材料提供给使用的 AI 产品。Skill 不需要长期储存原始聊天记录才能给出建议，也不保证得到升职、加薪或某种人际结果。
