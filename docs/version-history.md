## 恢复方式

只查看历史不会改变工作区：

```powershell
git show v0.1.0:mark-talk/SKILL.md
git show v0.2.0:mark-talk/SKILL.md
```

需要完整副本时，把对应 ZIP 解压到新目录即可；安装只选择其中的 `mark-talk` 目录。若要恢复 Git 历史，下面命令在项目根目录执行，目标目录必须尚不存在：

```powershell
git clone .backups/2026-10-21/mark-talk-history.bundle ../mark-talk-recovered
git -C ../mark-talk-recovered switch --detach v0.2.0
```

将标签换为 `v0.1.0` 可检查首版。恢复使用新目录，不需要覆盖当前项目，也无需 `reset --hard`。
