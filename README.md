# Mark Talk

中文 · [English](README.en.md)

给上司、导师或带教回消息，难的常常是把自己的工作、判断和诉求说清楚。Mark Talk 帮你整理当下要推进的事，必要时问一两个关键问题，再拟少量有不同取舍的回复。补充背景后继续改，选中一条后收敛成你会说的话，由你核对并发送。

聚焦职场和学业的向上沟通：汇报、求助、申请资源、问清标准、表达约束、回应批评和确认安排。你可以从一句话开始，不必建人物档案或上传全部聊天。

**当前目录是 `0.3.0` 候选，修订日期为2026-10-30，尚未正式发布。** 本轮留存Codex40条、千问去重42条有效答复；已收到一位参与者的10组完整反馈：候选获选3组、旧版5组、并列2组。修补聚焦主动表达责任、自然说明约束、选稿收敛与持久化授权，见[反馈与修补报告](tests/reports/2026-10-29-0.3.0-human-feedback-and-refinement.md)。[原测评汇总](tests/reports/2026-10-26-0.3.0-evaluation-summary.md)的失败和限制保留，仍未通过正式验收。稳定版可取 [0.2.0 固定提交](https://github.com/Theo-bang2025/mark-talk-skill/tree/82dd114484f0a92068c6096c4843a68202083807/mark-talk)。

## 从补充背景到一句能用的话

以下是手写演示，不是模型实测原文。

> **你：** 想申请一位测试同事支援两周，怕负责人觉得我没安排好。
>
> **助手：** 你们已经做过哪些检查？这两周主要需要补哪块测试？这两点能把申请的依据和用途说具体。
>
> **你：** 核心流程已经自测，跨部门账号权限还没测。下月上线，我和兼职同事没余力覆盖，主要需要权限验证和回归。
>
> **助手两种方向中的一条：** 想申请一位测试同事支援两周，重点做跨部门账号权限验证和回归。核心流程已经自测，目前我和兼职同事都没有余力覆盖这部分。工具计划下月上线，想请您确认能否协调人手。
>
> **你：** 用这版，短一点，别像邮件。
>
> **助手：** 想跟您申请一位测试同事支援两周，主要做账号权限验证和回归。核心流程已经自测过，但这部分我和兼职同事都没余力覆盖，想请您帮忙协调人手。

方法用于内部理思路，成稿按关系、媒介和你的习惯组织，允许省略、合并和调序。同类问题不要求固定开头或四段；变化也不靠随机换词。润色始终保留事实、立场、约束和承诺。

## 安装和开始使用

候选试用：从当前源码或本地候选 ZIP 取完整 `mark-talk/`，导入支持本地技能的客户端。目录应有：

```text
mark-talk/
  SKILL.md
  references/upward-methods.md
  references/relationship-card.md
```

可以对安装助手说：

```text
请从我提供的本地 mark-talk/ 目录安装技能，完整保留两个 references 文件。
核对 SKILL.md 版本是0.3.0、修订日期是2026-10-30，告诉我实际位置和三个文件的SHA-256；无法核实的请说明。
```

同为0.3.0的包仍需核对修订日期与散列；旧测评冻结于d4b5032，不能与本次源码混用。使用GitHub安装时核对实际分支与提交，确认其中已有本次修订。若使用0.2.0，请采用上面的固定提交，它没有方法库文件。完整步骤、Codex 路径和排错见[上手指南](docs/getting-started.md)。[千问办公官方说明](https://help.aliyun.com/zh/qwenwork/skills)提供 GitHub 和本地安装方式；客户端界面与实际支持需分别核对。

开启后另开对话，说眼前的事：

> 导师说初稿“论证不够扎实”，我想问清先改哪里，帮我写两条微信回复。

日常未自动调用时可明确说“使用 Mark Talk”；正式自动触发测试保留原输入。赶时间就说“先给一条能发的”，也可以继续说“采用第二条，更坚定，但别替我答应明天交”。[完整教程](docs/getting-started.md#从一句话到可用回复)展示补充、选稿和口吻修改。

## 关系卡由你保管

可选文本卡记录角色、目标、已确认事实、带依据的待验证判断和当前事项。可预览、纠正、删一条或整卡停用。跨会话需你保存并重新提供。

整卡停用后不再用旧字段或旧事项继续建议；之后你重新提供的事实可使用。修订卡文本不清除平台历史、记忆、附件或其他副本。明确管理某个存储副本是另一项按宿主实际能力执行的任务。见[卡片演示](docs/getting-started.md#关系卡完整走一遍)。
