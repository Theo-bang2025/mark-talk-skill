# 帮 Mark Talk 做一次内测

中文 · [English](README.en.md)

默认比较 **0.2.0 与 0.3.0 候选**：能否更好地完成向上沟通，补充后是否更贴合，选稿后是否更像自己。事实、承诺与卡片控制逐条检查，不以均分抵消错误。普通体验见[上手指南](../docs/getting-started.md)。这是验收计划，不是已通过的结果。

## 请 AI 一步步带你做

在独立指导对话中发送：

```text
请按本项目 tests/ai-guide.md 带我做 0.2.0 与 0.3.0 候选比较。
先读取 tests/README.md、tests/dialogue-scenarios.md、tests/inputs.md 和 tests/record-template.md，确认拿到了完整文件，并核对实际安装包的来源和版本。
一次只告诉我当前步骤和要保存的证据；缺少电脑操作能力就给手动步骤。
被测会话另开，不能看评分提示、事实表、历史报告和其他案例。
不能替我填写未观察的加载、动作、时间或主观感受。完整计划可以分配多人，未完成项按实际报告。
```

候选只在本地时，提供实际候选文档/包，不能假定 GitHub main 已含新版本。

## 固定包与环境

按[模板](record-template.md)记录产品/版本/模式、可见模型、后端不确定性、系统、采样、工具、其他技能、记忆/历史引用与实际隔离范围。不可见写不可见。

旧版固定 `v0.2.0` 提交 `82dd114484f0a92068c6096c4843a68202083807`；候选固定实际源码提交及三个文件 SHA-256。版本字符串不能唯一标识迭代。每条件只装对应版本，刷新/重开后核对文件。0.2.0 两文件，候选新增 `references/upward-methods.md`，不能同名两版同时开启。途中不更新包、模型、标准；修订后新建运行号并保留先前失败。

用实际开关/安装切换，不发送“忽略旧规则”模拟版本。自动触发测试只发送原始输入，不点名技能。核心与参考各记“可见已加载 / 可见未加载 / 未知”，附调用记录；事后问 AI 是否加载不能代替证据。显式加载诊断不替换原始结果。

## 上下文隔离

指导、评分、被测会话分开；测试目录、事实表、报告、答案不应被目标检索。被测工作区仅有当前案例必要材料，关掉文件窗口不算隔离。

新聊天不等于空记忆。每个案例/条件采用可验证独立范围；S8/S9-b 和各三轮任务共用各自会话。非破坏性关闭可控记忆/历史引用，两条件一致，不删除个人数据。逐例记工作区和共享宿主记忆范围，区分自动注入/主动读取/未知。无法隔离则称生态试用；平衡顺序不能清除持久状态。

引用别例、评分内容或额外背景时保留原文，先记疑似污染，有轨迹才确认来源。修正环境后的重跑另列。

## 默认验收：29 个新会话、40 次响应

完整输入与追答见 [dialogue-scenarios.md](dialogue-scenarios.md)：

1. 候选原回归：按 [inputs.md](inputs.md) 发 S1–S7、S8 后同会话 S9-b、独立 S9-a，共9会话10响应。除 S9-b 外，原回归首答追问就保存并止于该轮。
2. 候选高风险补跑：S1、S5、S6、S8 → S9-b 各再两次，共8会话10响应，每轨迹总计三次。
3. 两版迁移：T1–T4 单轮、T5–T6 三轮，各版6会话10响应，共12会话20响应。T1/T3/T5 旧版先，T2/T4/T6 候选先。T5 只按实际问题揭示事实；T6 固定纠正；第三轮固定选稿请求。事实表不可交目标。

S8 首答无论是卡或追问，都保存后直接追加 S9-b，不回答临时问题。S9-b 和多轮中间响应不是新会话或独立触发机会，40响应也不是40独立样本。

每轮保存真实输入、完整首答、会话/工作区代号、时间、调用/工具证据。不重抽、不挑最好。未配对、诊断、权限差异、失败执行与偏离单列。A1/A2、C1–C3、N1/N2 是另列诊断，不并入29/40；存储夹具仅用临时虚构文件，不扩大访问或删除真实数据。

## 评分与真实体验

另用评分会话读 [scenarios.md](scenarios.md)、[rubric.md](rubric.md)。先逐条引用证据，再看配对。v2.1 保留六维、补多轮与漏判解释；旧分不自动换名并入。

质量、产品格式、人类感受分开。首轮/最终稿分别看问题用途、实际揭示事实的采纳、纠正、是否重复已答问题、选稿后收敛。自然度结合媒介、关系、本人习惯判断，不统计同义词或凑四段。相关追问可以继续同一任务，无关推销需指出。

动作证据区分原始当轮工具轨迹、状态结果、参与者/核查 AI 摘要和纯文本声明。文件名吻合、时间戳不能单独证明主动检索，U1 不算通过。评分不授权搜索私人数据。

若遮蔽条件，由单独整理者去组名并随机编号，保留映射表不给评分者；记开发参与和历史接触。读完旧版再读候选是非盲评，文风仍可能泄露组别。

5位自愿者各体验2个虚构/脱敏任务，共10次。先独立选择，再核对事实；人类填写偏好、并列/都不选、改写量、本人语气、问题有用性和发送意愿。AI 不代填。记录实际字数、耗时和找正文时间，没测就写未记录。产品门槛见[场景末尾](dialogue-scenarios.md#门槛)，小样本不推断总体成功率。

## 报告与交回材料

保留 manifest、逐轮原文、工具证据、评分依据、偏离和局限。原回归、补跑、迁移分别统计；沟通和卡片分开。报告实际会话/响应/配对数、H1–H4、U1、污染、加载未知和人类缺失。公开开发案例不称未见留出。

开发显式加载、实际宿主自动触发和人类验收分别报告，未取得的门槛保留待验证。原件默认本地私有；分享前去私人路径/姓名/环境痕迹并记公开许可。真实私聊可只交匿名摘要，收到文件不等于获准公开。

## 可选旧协议：普通模型关闭/开启比较

历史校准可用 off/on：关闭跑9会话10响应，开启同一包再跑9会话10响应，合计18会话20响应；仍用 upward-v1.1，两条件 S8 → S9-b 同会话。它不是默认两版验收，不与29/40合为一个实验。隔离、证据、保留失败和主观反馈规则相同。
