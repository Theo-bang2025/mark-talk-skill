## 4. 不可丢失的范围与产品目标

原路线：标准 Skill 核心 → 可控关系档案 → 平台适配和长期记忆。当前先纵向深化员工/实习生与主管、研究生与导师等向上沟通。不扩展平辈、朋友、情感场景，不开发后台聊天同步、自动发送或大书籍数据库。

重点是用户真实觉得有用：把已做工作、产物、真实反馈和请求讲清楚，有依据时先给自己的建议再请上级确认；尊重而不卑微，不把所有判断推回领导。事实与承诺准确是底线，不能让输出只剩谨慎和免责声明。

信息足够直接给少量成句方案；确实影响写法时问一至两个关键问题；用户补充后更新内容，选中后默认收敛为一条。允许赶时间直接给短回复。相关的任务追问可保留，禁止一刀切“结尾不能问问题”。

八类方法：进展可见、有准备地求助、给建议再请决策、澄清标准、资源申请、尊重地表达约束、回应批评/误解、确认跟进。参考文件应短小、按需读取，包含原创例子与反例；不要抄整书或把机构方法当中文场景有效性证明。
