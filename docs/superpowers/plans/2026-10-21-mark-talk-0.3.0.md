# Mark Talk 0.3.0 Implementation Plan

> **For agentic workers:** Use `executing-plans` to implement this plan task by task. The tightly coupled skill and evaluation changes are edited in this session; independent agents are used for behavioral checks and final review.

**Goal:** Deliver a reviewable 0.3.0 candidate that helps users complete upward communication tasks through grounded methods and useful iteration.

**Architecture:** Keep the Markdown skill as the entry point. Put eight small communication methods in one on-demand reference, and keep optional text-card rules separate. Evaluate task completion and natural wording alongside factual and user-control boundaries.

**Tech Stack:** UTF-8 Markdown; ASCII model instructions; Git; Python standard-library structural checks and the installed skill validator.

## Global constraints

- Approved design: `docs/superpowers/specs/2026-10-21-upward-quality-design.md`; no new design approval required.
- Stay within upward workplace/academic communication; no database, automatic messaging or background memory.
- Methods organize internal reasoning. Output follows the relationship, medium and user's voice; no fixed four-part script or random synonym variation.
- Preserve facts, constraints, position and accepted commitments through every revision.
- Keep `tests/inputs.md` unchanged; preserve old tags and backups. Do not publish raw participant data.
- Version identifier is `0.3.0`; report it as a candidate until host and human release gates are supported. Do not create a release tag prematurely.
- External minimum campaign: 29 conversations / 40 responses; human task evaluations: 10 from 5 volunteers. Developer replay is separate evidence.
