# 给内测指导 AI 的操作约定

先读 [README.md](README.md)、[dialogue-scenarios.md](dialogue-scenarios.md)、[inputs.md](inputs.md)、[record-template.md](record-template.md)。确认是完整文件；只有摘要就直说。候选未同步 GitHub 时读取用户实际提供的本地包与文档，不凭仓库名称编造新版本内容。

## 指导

先确认协议：默认0.2.0/0.3.0候选验收；off/on仅历史校准；开发显式加载和诊断独立。已给版本、模型、安装、开关、权限、记忆范围不重问。一次只给当前操作、预期可见状态和要保存的证据；无操作能力给手动步骤，不声称已点击、重启或导出。

逐版本核对源码提交/三个文件散列（旧版仅两文件），只启用对应包。保持相同产品/模型/工具/可验证隔离范围，不让目标读取评分、事实表、历史报告或其他案例。仅换聊天不能证明隔离，平衡顺序也不能清除共享记忆；不删除个人数据制造空环境。不能隔离就记录生态试用。

默认29新会话40响应：候选原回归9/10 + 高风险补跑8/10 + 两版迁移12/20。每轨迹S1/S5/S6/S8→S9-b总计三次。S8回答后保存，再直接在同会话追加S9-b，即使首答是追问也不补答；S9-a单独新开。其他原回归追问止于首轮。迁移T1/T3/T5旧版先，T2/T4/T6候选先。

T5按实际问题从执行者事实表摘取对应原句，没问则用固定第二轮提示；不自动供给全部背景。T6按固定事实纠正。两任务第三轮固定选稿/语气请求。同一任务沿用原会话，每轮记录实际输入；不把分支表发给目标。两版有同样取用事实机会，不一定获得相同信息量。

自动触发只发当前纯输入，不点名技能。核心/参考加载独立观察；未知写未知。S9-b和多轮续答不计新触发。显式点名复试、A/C/N诊断另计，不替换原结果。保存每个首答、全部失败、权限拒绝与协议偏离。发现别例内容先记疑似污染，见轨迹才确认来源；重跑另存。

存储诊断仅在授权的临时虚构夹具中做，先核对绝对目标。测试不授权全盘搜卡、删真记忆或操作他人客户端。含糊但明确的存储请求先辨目标。若仅观察到声明，不能说动作已执行。

## 评分

收齐后另读 [scenarios.md](scenarios.md)、[rubric.md](rubric.md)。评分者知道组别、参与开发或读过旧结果就如实记录非盲。若遮蔽，另请整理者去组名随机编号，映射表不给评分者；风格仍可能泄露。

逐条列真实输入、回答原句、依据。部分交付、短聊、手机工作、灵活进场都是可能的实质承诺，外侧免责不能修复。S6今天/明天十分钟会谈是H1；S9-b整卡停用后沿用旧事项拉任务是H4。人愿发送也不能补足虚构事实。

首轮与最终轮分别判断问题是否必要、事实补充/纠正是否进稿、选稿是否收敛及口吻是否贴合。更坚定不能变拒绝任务，更委婉不能加让步。相关问题可以推进同一任务，不因问号扣分；无关推销具体指出。方法不是固定四段，也不靠随机换同义词。

卡片预览/完整卡/整卡停用使用相应口径，不要求所有任务都多选。格式约定另记，不能因基线未学八字段自动扣通用质量分。

工具证据按原始调用/状态、转述、核查摘要、纯文本分别标明。文件名吻合、末态、时间戳不能证明本轮主动读写；自动注入与检索分开，证据不足记U1不算通过。不要为了评分主动搜索私人材料。

人类独立初选后再做事实核对，人类填写偏好、并列/都不选、改写、口吻、问题用处和发送意愿；AI不代填。实际字数可算，耗时/找正文时间没测写未记录。5人10任务门槛按设计，不伪造缺失项。

最后分别汇总原回归、补跑、迁移；沟通与卡片分开。报告实际完成数、配对、H1–H4、U1、污染和未知。开发回放、真实宿主和人类证据独立；未满足发布门槛保留候选状态。公开前去标识化并遵从参与者许可。
